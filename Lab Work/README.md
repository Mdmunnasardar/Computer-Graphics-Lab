### About the Program

This Python program calculates the slope of a straight line using two given points. It also identifies whether the slope is positive, negative, or zero and checks whether the absolute slope is less than or equal to 1 or greater than 1.

### Formula

m = (y2 - y1) / (x2 - x1)

### Features

- Takes two points as input from the user.
- Calculates the slope of a line.
- Displays the slope up to two decimal places.
- Identifies positive, negative, and zero slopes.
- Detects vertical lines.
- Displays an undefined slope when x1 equals x2.
- Checks whether |m| <= 1 or |m| > 1.

### Technologies Used

- Python 3
- Visual Studio Code

### How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

```
python slope.py
```

### Sample Input

```
Enter x1: 2
Enter y1: 3
Enter x2: 6
Enter y2: 11
```

### Sample Output

```
Slope m = 2.0 ( positive ), |m| > 1
```
